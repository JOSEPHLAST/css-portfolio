# CSS PORTFOLIO 🎨

A personal portfolio website showcasing projects, skills, and contact details, designed with CSS for a modern and responsive layout.

## FEATURES
✅ Fully responsive design for mobile and desktop.   
✅ Clean and modern UI.   
✅ Sections for About, Projects, and Contact.   
✅ Smooth animations and transitions.

## LIVE DEMO
[🚀 Live Preview](https://josephlast.github.io/css-portfolio/)

## TECHNOLOGIES USED
	•	HTML – Page structure.
	•	CSS – Styling, layout, and animations.

## INSTALLATION & USAGE
	1.	Clone the Repository:
git clone https://github.com/JOSEPHLAST/css-portfolio.git   
cd css-portfolio   

	2.	Open index.html in a browser (Chrome recommended).
